Zero Breach Scanner

Checks files you choose for traces of known spyware, stalkerware and mercenary-spyware infrastructure. Browser version of Zero Breach Toolkit.

Your files stay on your device

Everything is checked inside this page. Nothing you choose is uploaded, and the page is not allowed to contact any website except one: the Update button, which downloads public indicator lists from raw.githubusercontent.com. It never sends your files. Turn off Wi-Fi after the page loads if you want to be sure.

What can I choose?
  • An iPhone backup folder (made with Finder or iTunes; encrypted backups work, you will be asked for the password). It is the folder holding Manifest.db.
  • An Android collection from AndroidQF (the folder with packages.json, getprop.txt and similar), including a backup.ab.
  • A browser profile folder (Chrome, Edge, Firefox, Safari) or any folder of saved files: history, downloads, cookies and text files are searched.
  • A web page cannot look at system locations by itself. Copy or pick the folders you want checked.

Working…

The password is used only in this page to unlock the backup and is cleared afterwards.

Honest limits

  • This is a reduced browser port of a much larger desktop tool, written independently. It has been tested only on synthetic data, not on real spyware or real encrypted backups. For anything serious, use the original desktop tool and get expert help.
  • It only finds known, published indicators. "Nothing found" is never proof a device is clean.
  • Not included: YARA rules, Windows registry, Prefetch, Amcache and event logs (these are only searched as raw text), and deeper iOS data such as sysdiagnose.
  • If you may be a target of surveillance, contact the Access Now Digital Security Helpline or Amnesty's Security Lab.
